# 简易直楼梯探索历程（2026-09-22 ~ 09-23）

目标：让 microduck（25cm/800g 双足）爬上**最普通的直楼梯**——全宽踏级、脚掌整只放平、顶部有平台。
终点几何：全宽 60mm 踏级（鸭脚 54mm）、12 级 + 顶部平台（36cm 高）。
环境代码：`third_party/microduck-playground/experiments/desk-climb/source/src/mjlab_microduck/tasks/microduck_simple_stairs_env_cfg.py`（+ `microduck_jump_step_env_cfg.py`）。

## 背景数据（探索前测量）

- 官方交替梯策略（24-26mm 级高可靠包络）：脚 apex 净空 median **66.6mm** / p90 72.4 / max 78.8（64 env 全量 1671 步 FK 分析）
- 运动学极限：单脚最大抬升 ~170mm（关节限位 Monte Carlo）——策略只用 ~46%
- 全宽踏级约束：同侧间距 1 级 → 级高 ≥ 29mm（趾尖间隙，`ladder.py:min_riser_m`；**reset 会钳制，低于 29mm 的课程无效**）

## 路线时间线

### v1：固定 30mm 级高硬上（2026-09-22 晚）

- **设计**：全宽 60mm 踏级、30mm 级高、26.6°、单级固定难度，从零训 2000 迭代 @4096
- **结果**：失败。三档评估到顶率全 0，卡在 ~2 级（60mm 高）就前倒（fall_forward 46-93%）
- **结论**：起步即硬难度，无课程缓冲学不动（计划风险项 3 坐实）
- 产物：`checkpoints/v1-fixed30mm-ck1999.pt`、`evals/eval-simple-{1000,1500,1999}.json`、`videos/v1-ck1999.mp4`

### v2：开放式立板 5 级课程（2026-09-22 深夜）

- **设计**：小级高放缓倾角 → run > 踏级深度形成开放立板（脚走级间空隙，绕开 29mm 钳制），15→30mm 五级课程
- **发现**：riser 被 reset 钳到 29mm 下限，实际变成"29mm 固定 + 角度课程 13→21°"
- **结果**：部分好转但未达标。摔倒率降到 0-2%（L0），爬升缓增（L4 最高级 p50 0.7→1.7），到顶率仍 0
- 产物：`checkpoints/v2-clamped29mm-ck1999.pt`、`evals/eval-v2-*.json`、`videos/v2-ck500-stall.mp4`（原地晃）、`videos/v2-ck1999-stall-at-tread1.mp4`（走到第一级定住）

### v2r：同配方续训判决实验（2026-09-23 凌晨）

- **设计**：v2 基础上同配方续训（军规路径），目标 6000，验证"只是迭代不够"
- **结果**：**判决性证据**——ckpt 4000 与 ckpt 6200 评估完全一致（都是 1 级、到顶 0、摔倒 0）。2200 迭代零进步，续到一半杀掉（省 ¥3）
- **结论**："加步数"证伪，~1 级墙是结构性的
- 产物：`checkpoints/v2r-continuation-ck6200.pt`、`evals/eval-v2r-{4000,6200}.json`（两文件逐字节可读对比）、`videos/v2r-ck6200.mp4`
- 教训：rsl_rl resume 时 `max_iterations` 是增量不是总量；`--agent.load-checkpoint` 只收文件名

### v3：双脚各自侧目标（2026-09-23 早）

- **设计**：上游 `_stair_foot_target_info` 对全宽踏级给双脚**同一个中线目标**（2026-09-04 landing study 记载过收敛步态犹豫 bug，作者只修了 landing）→ v3 给每只脚各自侧目标，`MICRODUCK_SIMPLE_STAIRS_PER_SIDE=1` 开关
- **结果**：**更差**。L0 摔倒率 100%（climb 命令），爬升 p50 0.8-0.9 级（v2 是 1.0-1.7）
- **结论**：目标几何不是瓶颈。综合 v1-v3 + 跳跃包络测量，锁定根因：**29-30mm 超出迈步步态家族 ~25mm 的可靠包络**
- 产物：`checkpoints/v3-perside-ck1999.pt`、`evals/eval-v3-*.json`、`videos/v3-ck1999.mp4`

### v4：单级跳台（跳跃路线，用户提议）（2026-09-23 上午）

- **设计**：分解风险——先只做"跳上一级台阶"：平地出生，平台高 = twist 命令 vx（30/40/50/60mm 随机），势能进度 + 一次性成功 bonus + |a_z| 冲击税（episodic trick 预算 ~2000 迭代）
- **依据**：官方步态抬脚净空 66-79mm（30mm 应该稳过）；物理极限 ~170mm（50mm+ 有戏）；跳跃无单腿支撑阶段，绕开迈步的平衡难题
- **结果**：（训练中，结果见 `evals/eval-jumpstep-*.json` 与 `videos/`）
- 产物：`checkpoints/`、`evals/`、`videos/`

## v4-v7 跳跃线四轮配方迭代（2026-09-23，判决轮收尾）

新任务 `Mjlab-JumpStep-MicroDuck`（`microduck_jump_step_env_cfg.py`）：平地出生，台前 0.18-0.25m，平台高 = twist vx（30-60mm→收窄 25-35mm），跳上台站稳 0.4s 成功。

| 轮 | 失败模式（全部有视频） | 根因（探针实测） | 修法 |
|---|---|---|---|
| v4 | 面壁站桩，永不抬脚 | 奖励全是躯干垂直/前进势能，无"上台"引导 | 加前进势能 |
| v5 | 连接近都不学了 | 台上出生 30% + 站桩成功 20 分 → 站桩全局最优 | 成功分级（台上 3 分） |
| v6 | 趴台盆地：胸口趴台沿，脚钉地 | 前进势能测躯干 → 趴台不起跳也吃满 | 前进改测双脚 + 首脚踏顶奖 w5 + 趴台接触税 |
| v7 | **单脚踩台**：右脚踩上台沿后按兵不动 | first_foot 奖励被单脚姿势农场化（事件率 ×2.6 但第二只脚不上） | — |

**判决结论**：4 轮迭代后，"远台出生→双脚上台+站稳 0.4s"完整成功率仍为 0（每轮 512 envs 三档评估）。但行为链是真实推进的：站桩 → 接近 → 趴台 → 首脚踏台。成功的上游环节全部打通（台上出生稳站 77%、接近链路 55% gate 命中、首脚踏台频繁出现）。
**环境 bug 备忘**：`rel_forward_envs` 继承自速度模板会改写命令值（20% 的局平台变 30cm 悬空，废掉一轮训练）——复用 twist 槽做非移动命令时 rel_* 必须全置零。上游梯子任务同样带此坑（~20% 局爬速命令被改写 0.3m/s）。
**已知下一步（未执行）**：v8 方向——首脚奖励防农场（要求另一脚离地/空中）或第二只脚的分级 shaping，或 success 权重 20→40 压过单脚盆地。

## v8：首脚奖防农场 + success 40（2026-09-23，第五轮，收尾轮）

- **修法**（按 v7 判决的既定方向）：首脚踏顶奖要求**另一脚腾空**（接触中的脚不计分，防单脚踩台农场化）+ success 权重 20→40 压过单脚盆地。子模块 commit 80b3e8c。
- **训练**：1024 envs × 2000 迭代（run 目录 `logs/rsl_rl/jump_step/2026-09-23_13-47-*`）。末段 Mean reward −0.06、landed 0.21-0.25、first_foot 0.004。
- **评估**（`evals/eval-jsv6-{1000,1500,1999}.json`，512 envs 两档）：**三个存档点全部 0/512**（24-30mm、30-35mm 两档全 0）。
- **视频行为**（`videos/v8-jumpstep-ck1999.mp4`）：**台前反复深蹲蓄力但蹬不出去**——下蹲-回弹循环，起跳前摇已经出现，但从未真正离地腾空。
- **判决**：五轮迭代五种盆地（站桩→不接近→趴台→单脚踩台→深蹲不蹬），行为链推进到"起跳前摇"为止，远台出生完整成功率五轮全 0。失败模式已从"奖励被农场化"转为"动力链缺口"：下蹲蓄力有了，缺的是把势能转成离地腾空的最后一脚。
- **产物**：`checkpoints/v8-jumpstep-ck1999.pt`、`evals/eval-jsv6-*.json`、`videos/v8-jumpstep-ck1999.mp4`。v7 档（run 2026-09-23_20-10-43）仍在实例数据盘未拉回。
- **候选下一步（待用户拍板）**：
  - a. **飞行态出生逆向课程**：机器人直接生在平台上方空中自由落体落台，体验末端状态（AGENTS.md 明写的 nearly-done spawn 治最后一公里），配合已出现的深蹲蓄力行为，最有希望接上。
  - b. **真·高度课程**：5/10/15/20/25/30mm 逐级抬台（此前 25-35mm 起步过高）。
  - c. **放弃跳跃回 25mm 迈步**：给上游 reset 钳制（29mm 下限）打补丁。

## v9：飞行态出生逆向课程（2026-09-24 凌晨，用户拍板方案 a）

- **设计**：新增 `SPAWN_AIRBORNE` 出生模式——机器人出生在平台正上方 8-15cm 空中（xy 各向异性抖动 ±5mm(x)/±30mm(y)），自由落体落台。出生分布 airborne 0.6（课程驱动递减）/ edge 0.2 / far 补足；课程由 airborne 局 landed 成功率驱动（200 局窗口，双向回退）。airborne 局 success 按 0.075 缩放（=3 分，防 nearly-done 出生农场化，与 platform-top 同例）。子模块 commit a06eb7b。
